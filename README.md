# Two Rats Films

This repository contains the website for **Two Rats Films**, a film production company. The site is a static page (HTML, CSS and JavaScript) that also hosts the crowdfunding campaign material for our films.

## Live site

The site is hosted on GitHub Pages at:

**https://iamsumit.github.io/tworatsfilms/**

This is a temporary address. It will move to a custom domain once one is purchased.

## Repository structure

| Path         | Contents                        |
| ------------ | ------------------------------- |
| `index.html` | Main page of the site           |
| `css/`       | Stylesheets                     |
| `js/`        | JavaScript                      |
| `images/`    | Images used on the site         |
| `videos/`    | Video assets                    |

## Running locally

No build step is needed. Open `index.html` in a browser, or serve the folder with a simple local server:

```sh
python3 -m http.server 8000
```

Then visit http://localhost:8000.

## Deployment

The site is served by GitHub Pages. Changes pushed to the `main` branch are published automatically.
